SMART ERP Desktop - نسخة اختبار العملاء
=======================================

التشغيل
-------
1. فك ضغط الملف بالكامل إلى مجلد تملكه وتستطيع الكتابة فيه.
2. افتح SmartErpDesktop.exe.
3. هذه نسخة اختبار x64 مستقلة وتتضمن .NET؛ لا تحتاج إلى تثبيت .NET منفصلاً.

قاعدة البيانات والخصوصية
-----------------------
يحفظ البرنامج قاعدة البيانات في:
%LOCALAPPDATA%\SmartErpDesktop\smarterp.db

لا تتضمن حزمة التثبيت قاعدة بيانات المطور أو بيانات عملاء حقيقية. عند التشغيل لأول مرة على حساب Windows لا يحتوي على بيانات SMART ERP سابقة، ينشئ البرنامج قاعدة البيانات ويضيف سجلات تجريبية مرة واحدة. لا تتم إعادة تهيئة البيانات عند كل تشغيل. إذا كان على الحساب قاعدة بيانات SMART ERP سابقة، فسيستخدمها البرنامج كما هي.

هذه نسخة مخصصة لاختبار العميل. استخدم بيانات اختبار فقط، ولا تدخل بيانات عملاء حقيقية أو معلومات سرية.

النسخ الاحتياطي والاستعادة
-------------------------
من داخل البرنامج افتح الإعدادات ثم اختر "إنشاء نسخة احتياطية" وحدد مكاناً آمناً خارج مجلد البرنامج. تحفظ النسخة قاعدة البيانات النشطة كاملة، بما فيها إعدادات المنشأة.
لاستعادة نسخة، اختر "استعادة نسخة احتياطية" من الإعدادات. الاستعادة تستبدل قاعدة البيانات النشطة؛ أنشئ نسخة احتياطية أولاً.

الطابعة ومعاينة الفاتورة
-----------------------
خيارات الطابعة ومقاس الورق (حراري 58 مم، حراري 80 مم، أو A4) موجودة في الإعدادات. اختر طابعة متوافقة ومقاساً يدعمه تعريف الطابعة. قد تختلف الهوامش والقص حسب الطابعة والتعريف.

الإبلاغ عن مشكلة
----------------
أرسل وصفاً مختصراً للخطوات التي أدت للمشكلة، الشاشة المتأثرة، ونص رسالة الخطأ إن ظهرت، مع إصدار Windows ومقاس الورق المستخدم. لا ترسل قاعدة البيانات أو بيانات شخصية ضمن البلاغ؛ أرفق نسخة اختبار منزوعة البيانات الحساسة عند الحاجة وبعد مراجعتها.
